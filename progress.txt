      independently written CENSUS (takeRoomCensus: same definitions, written
      with subqueries and make_interval instead of joins and string casts) taken
      in the same breath as the repository call. Ambient rows land in BOTH
      numbers, so a wrong predicate — counting a private room, a deleted
      message, a system notice, an expired room's presence — still shows up as a
      disagreement, while concurrent traffic cannot manufacture one. Where an
      absolute claim was still needed the tests use a floor on rows they own.
      The API-level privacy test was hardened the same way: the deterministic
      proof is that neither the private room's content nor its slug appears
      anywhere in the raw body, and the EXCLUSION is pinned one layer down.
