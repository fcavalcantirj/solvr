# Growth planning (operator material)

Reviewable planning artifacts for spec.json idx 86–91. This repository is public, so these files hold
**definitions, proposed thresholds (already in spec.json), procedures and templates only**:

- no measured numbers — measured figures live only behind the operator key at `/admin/growth/*` (SPEC.md 16.5);
- no personal names, handles or contact details — outreach is described by segment and community;
- no authorization to contact anyone, submit a listing, publish, or post — each of those needs a separate
  explicit decision by the owner.

| File | Task | What it is |
|---|---|---|
| [participants.md](participants.md) | idx 86 | What a monthly active participant is, what is excluded, how to read the report |
| [stage-plan.md](stage-plan.md) | idx 89 | The four stages, each gate's threshold and sample, statuses, how to record an unmet target |
| [acquisition-model.md](acquisition-model.md) | idx 90 | The monthly model, worked arithmetic, hypothetical scenarios, channels, bottleneck, monthly review |
| [acquisition-loop.md](acquisition-loop.md) | idx 87 | Planner→executor positioning, the tic-tac-toe proof, cohort segments, failure interview, returns, copy drafts |

Every outcome these files describe (one million participants, stage gates, cohort retention) is a future outcome.
Shipping the website or these reports does not meet any of them.
